# ⚽ FC CHAMPIONS MOBILE (Ultimate Soccer & Squad Builder)

![FC Champions Mobile Preview](preview.jpg)

**FC Champions Mobile** adalah game sepak bola web interaktif bergaya **EA Sports FC / FIFA Mobile** dengan grafis HD 60 FPS, sistem bursa transfer beli/jual pemain, manajemen taktik ganti pemain & formasi, serta buka paket kartu (*pack opening*) dengan animasi *walkout* yang spektakuler.

---

## 🌟 Fitur Utama

- 🏟️ **Gameplay Pertandingan Sepak Bola HD (60 FPS):**
  - Lapangan rumput bermotif garis (*striped mowed turf*) dengan fisika bola 3D realistis (gesekan rumput, elevasi ketinggian *Z-axis*, dan pantulan tiang gawang).
  - Papan skor digital, timer 90 menit pertandingan, radar minimap 2D posisi 22 pemain, komentator langsung, dan selebrasi gol dengan konfeti emas.
  - **Kontrol Fleksibel:**
    - **PC / Laptop:** `WASD` / Panah untuk bergerak, `J` untuk Passing, `K` untuk Shooting / Power Shot, `L` / Spasi untuk Sprint & Slide Tackle.
    - **Mobile / Tablet:** *Virtual Joystick 360°* + Tombol Aksi Taktil (*Pass, Shoot, Tackle, Sprint*).

- 📋 **Manajemen Skuad & Pergantian Pemain:**
  - Pilihan formasi taktik resmi dunia (**4-3-3 Attack**, **4-4-2 Classic**, **3-5-2 Midfield Control**, **4-2-3-1 Wide**).
  - **Ganti Pemain (Substitusi):** Klik kartu di lapangan *Starting XI*, lalu klik pemain di **Bangku Cadangan (*Bench*)** atau **Reserves** untuk menukar pemain secara instan.
  - Perhitungan dinamis **Team OVR** dan **Team Chemistry**.

- 🛒 **Bursa Transfer (Transfer Market):**
  - Cari dan beli bintang sepak bola dunia (seperti **Pelé**, **Ronaldo Nazário**, **Mbappé**, **Haaland**, **Messi**, **C. Ronaldo**, **Zidane**, **Van Dijk**, dll.) menggunakan koin hasil pertandingan.
  - Jual pemain cadangan untuk menambah pundi-pundi koin klub.

- 🎁 **Buka Paket Kartu (Pack Opening & Walkout):**
  - Buka *Starter Pro Pack*, *Gold Elite Pack*, dan *Prime ICON Champions Pack* dengan animasi kartu bersinar (*walkout reveal*) dan efek suara kejayaan.

- 🔊 **Web Audio Synthesizer:**
  - Suara peluit wasit, dentuman tendangan bola kulit, getaran jaring gawang, dan gemuruh penonton stadion tanpa memerlukan file audio eksternal.

- 💾 **Penyimpanan Lokal Otomatis (*LocalStorage*):**
  - Koin, gems, koleksi kartu pemain, formasi aktif, dan riwayat pertandingan tersimpan otomatis.

---

## 🚀 Cara Menjalankan Game

1. Cukup buka berkas **`index.html`** langsung di peramban web (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, dll.).
2. Tidak memerlukan server backend atau instalasi dependensi tambahan (*Zero dependencies*).
